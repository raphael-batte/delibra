Design system and site components

Mock of two menus. Tile on the left — workspace level: create, import, switch between storybooks, shared settings and About. Name with chevron — active storybook level: its settings, copy, export, delete. Boundary exactly like Figma: square — app, name — document.

The Library / Local badge is not decoration: a library brand lives as a folder on disk and survives storage cleanup; a local one lives in the browser and does not. That is why Delete is disabled for library brands — the browser cannot delete a folder, and a menu item that does not match its action is worse than none.
